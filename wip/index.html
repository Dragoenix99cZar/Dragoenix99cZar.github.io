3D Software Renderer & OBJ Viewer

Bare-Metal 3D Rasterization Pipeline
Description

A software 3D graphics pipeline performing perspective transformations, camera rotations, and mesh rasterization without WebGL, hardware acceleration, or GPU libraries.

Technologies Used
C (clang wasm32) WebAssembly HTML5 Canvas 2D 3D Matrix Math Wavefront .OBJ

Compiler Pipeline EXP_03

Stacky Compiler & VM Pipeline

5-Stage Visual Language Execution Engine
Description

An interactive compiler design educational visualizer demonstrating each discrete phase of program compilation from raw infix text strings down to stack-machine bytecode execution.

Technologies Used
Vanilla JavaScript Lexer / Tokenizer Shunting-Yard RPN ASCII AST Tree Stack Virtual Machine
Architecture Overview
Linear 5-phase compiler: (1) Lexer with unary deduction → (2) Shunting-Yard operator precedence queue → (3) Hierarchical AST generator → (4) Bytecode opcode generator (PUSH/LOAD/ADD/POW) → (5) Stack runtime executor.
Vision & Roadmap
Demystify compiler design and intermediate representation (IR) pipelines. Expand toward custom control-flow instructions (JMP, IF, LOOP) and a bytecode disassembly debugger.
